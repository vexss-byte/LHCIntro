# Laper Hardcore Intro (Fabric 26.3)

Build otomatis lewat GitHub Actions (tab Actions -> Run workflow -> download artifact jar).

## Setup sekali
1. Berdiri di TENGAH panggung -> /lhc setcenter
2. Berdiri di PINTU/lengkungan tempat member muncul -> /lhc setentrance
   (member berjalan dari pintu ke tengah; kamera berada di sisi depan tengah)
3. /lhc members online   (atau /lhc members add <nama>, boleh nama pemain yang offline)

## Command (OP)
/lhc play intro            putar intro penuh untuk semua pemain online
/lhc play member <nama>    preview satu member (untuk dirimu sendiri)
/lhc stop                  hentikan
/lhc members add|remove|list|clear|online
/lhc time walk <detik>     durasi jalan  (default 5)
/lhc time pose <detik>     durasi pose   (default 5.5)
/lhc test firework
